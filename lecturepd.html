Lecture → Split → Project Support

During the lecture there is one main student distribution with only marginal overlap with the teacher. Ending the lecture triggers a split: one engaged group remains slightly overlapping (K rises a bit), while several groups move away to the right and narrow (σ↓), reducing overlap with each other (balkanisation). Project support (institutional constraint) then increases K strongly for the engaged group.
